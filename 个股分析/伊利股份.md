## 商业模式

- **业务定位**：中国最大的综合乳制品企业，覆盖从液态奶到奶粉、冷饮、奶酪的全品类乳品
- **收入结构**（2025年）：
  - **液体乳** 704.22亿（占60.7%）— 核心基本盘，金典/安慕希为细分第一
  - **奶粉及奶制品** 327.69亿（占28.3%）— 第二增长极，婴配粉市占率18.1%行业第一
  - **冷饮产品** 98.22亿（占8.5%）— 连续31年行业第一
  - **其他**（奶酪/牛肉/B端） 15.32亿
- **客户/市场**：以 C 端消费者为主，品牌矩阵实现全消费层级覆盖（高端金典→大众优酸乳），渠道触达城市到乡镇
- **2026年目标**：营收 1215亿元（+4.8%），利润总额 136亿元

## 竞争优势（护城河）

- [x] **品牌溢价** — 金典、安慕希、畅意 100% 等品牌矩阵覆盖全消费层级
- [x] **规模/成本优势** — 中国最大乳企，全球81个生产基地，上游奶源控制力强
- [x] **渠道壁垒** — 深度分销模式，终端掌控力强于蒙牛的大经销模式
- [ ] 网络效应/转换成本
- [x] **全品类统治力** — 液态奶、奶粉、冷饮三大品类均排行业第一，竞争对手望尘莫及

**综合评估**：
伊利拥有中国乳业最宽的护城河。**全品类均衡布局（液态奶~61% / 奶粉~28% / 冷饮~9%）**是核心壁垒——蒙牛~80%依赖液态奶，行业下行时单一品类承压，而伊利通过多品类对冲风险。2025年奶粉反超成为行业第一，验证了2021年战略的执行力。此外，**高分红承诺（2025-2027年 ≥75%净利润）**形成了价值投资的股东回报闭环。

## 行业分析

- **行业阶段**：**成熟期**，但结构升级空间大（高端化/功能化/健康化）
- **竞争格局**：伊利断层式领先，2025年与蒙牛的差距进一步拉大（伊利净利润115.65亿 vs 蒙牛15.4亿），行业格局从"双寡头"演变为"一超"
- **周期性**：**弱周期**（乳制品为日常消费品），但受原奶价格波动影响毛利率
- **中长期趋势**：
  - 功能性营养（2030年市场规模预计3000亿）→ 伊利已布局药食同源、养生牛奶
  - 成人奶粉受益于老龄化趋势，伊利连续11年行业第一
  - 国际化：东南亚/中东/美国市场扩张中
