# 📊 高息股选股看板

## 🏆 精选排名（前 20）

按综合评分降序，聚焦核心选股指标，分数是由各个评分综合计算出来的，高评分并不代表是好股票

```dataview
TABLE 
  最新评分 as "评分",
  最新股息率 as "股息率(%)",
  最新市盈率 as "PE",
  最新ROE as "ROE(%)",
  最新净利同比增长 as "净利同比(%)",
  最新负债率 as "负债率(%)",
  最新总市值 as "市值"
FROM "股票池"
WHERE 状态 = "在池"
SORT 最新评分 DESC
LIMIT 20
```

## 💰 高股息排行

股息率最高的股票，由于是TTM数据，部分公司存在当年中期分红 + 去年分红的情况，导致股息率很高，请注意分辨

```dataview
TABLE 
  最新股息率 as "股息率(%)",
  最新评分 as "评分",
  最新市盈率 as "PE",
  最新负债率 as "负债率(%)",
  最新总市值 as "市值"
FROM "股票池"
WHERE 状态 = "在池"
SORT 最新股息率 DESC
LIMIT 20
```

---

## 📈 财务质量排行

ROE 领先的股票，盈利能力是分红的基础，筛选结果由于部分公司有特殊情况，可能会失真，请注意分辨

```dataview
TABLE 
  最新ROE as "ROE(%)",
  最新毛利率 as "毛利率(%)",
  最新净利率 as "净利率(%)",
  最新净利同比增长 as "净利同比(%)",
  最新评分 as "评分",
  最新股息率 as "股息率(%)"
FROM "股票池"
WHERE 状态 = "在池" AND 最新ROE > 0
SORT 最新ROE DESC
LIMIT 20
```

---

## 🛡️ 低风险精选

负债率低于 50%、股息率 ≥ 4.6% 的优质股

```dataview
TABLE 
  最新评分 as "评分",
  最新股息率 as "股息率(%)",
  最新市盈率 as "PE",
  最新ROE as "ROE(%)",
  最新负债率 as "负债率(%)"
FROM "股票池"
WHERE 
  状态 = "在池" 
  AND 最新股息率 >= 4.6
  AND 最新市盈率 > 0
  AND 最新负债率 < 50
SORT 最新评分 DESC
```

## ⚠️ 高风险警示

负债率超过 70% 的高息股，需警惕财务风险

```dataview
TABLE

  最新市盈率 as "PE",
```

## 📝 个股分析联动

通过 [[Templates/个股分析模板|个股分析模板]] 创建深度分析笔记后自动关联

```dataview
TABLE 
  股票代码 as "代码",
  行业 as "行业",
  股息率 as "股息率(%)",
  创建日期 as "分析日期",
  状态 as "状态"
FROM "个股分析"
SORT 创建日期 DESC
```

> 提示：在选股池找到感兴趣的股票后，运行「个股分析模板」即可创建分析笔记，自动双向链接。
