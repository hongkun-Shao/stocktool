基于 Obsidian 的高息股自动筛选工具。从 OSS 拉取开发端预生成的归档数据，在本地完成筛选入池、评分排名和历史追踪。

## 快速开始

1. 用 Obsidian 打开本文件夹
2. 安装 **Templater** 和 **Dataview** 插件（已在 `.obsidian/plugins/` 中，启用即可）
3. 打开 `选股启动器_用户端.md`，按按钮操作

## 每日操作

```
打开选股启动器 → 拉取数据(2-5秒) → 筛选入池(10秒) → 查看排名
```

详细说明见 [`新手教程.md`](新手教程（必看）.md)。

## 目录结构

```
├── 选股启动器_用户端.md    # 启动台，一键执行
├── 选股配置.md              # 筛选参数和评分权重
├── 新手教程.md              # 从零开始的使用指南
├── Templates/
│   ├── 用户端/
│   │   ├── 每日数据拉取脚本.md  # 从 OSS 下载归档
│   │   └── 每日筛选脚本.md      # 筛选入池 + 评分排名

│   └── 个股分析模板.md        # 深度分析笔记模板
├── 股票历史记录/             # 每日全量数据快照
```

## 数据来源

数据由开发端通过 Tushare Pro API 抓取并上传至 OSS，用户端零 API 调用。

## 依赖

- Templater 插件
